# CBETA 一手底本（TEI XML）

本目录存放**引文回源校勘所用的一手经藏文本**（TEI/P5 XML），为
`scripts/quote_from_cbeta.py` 之默认底本来源（回退次序：本目录 → 环境变量
`CBETA_T279_XML` → 旧临时路径）。

依编务原则「**考证优先**」「**原文是什么语言就用什么**」：中文经卷之「原文」
即所录字形，故校勘须以一手 TEI 为准，**不得依简繁转换器或记忆**。
