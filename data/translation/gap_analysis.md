## 二、A 类差异：藏文独有品目（核心发现）

### Ch.11 — 如来华严品 (Tathāgatāvataṃsaka)

| 维度 | 详情 |
|------|------|
| **藏文位置** | 第11品：毗卢遮那品(Ch.10) 之后、如来名号品(Ch.12) 之前 |
| **汉文状态** | 六十华严：无 · 八十华严：无 · 四十华严：不涉及 |
| **梵文对应** | `Tathāgatāvataṃsaka` — 名称意为"如来之华严/庄严" |
| **可能义理** | 据品名推测，此品应阐述如来以华严三昧展现的庄严境界 |
| **关联汉文经典** | 《大方广如来不思议境界经》(T10n0301, 实叉难陀译) — 同译者在译八十华严期间另译 |
| | 《大方广佛华严经不思议佛境界分》(T10n0300, 提云般若译) |
| | 《佛华严入如来德智不思议境界经》(T10n0303, 阇那崛多译) |
| **对译优先级** | 🔴 **P0 — 最高优先**。此品汉文全缺，学术价值最高 |
| **内容获取** | B 阶段将通过 84000/BDRC 获取藏文原文，做内容结构大纲 |

### Ch.28 — 普贤宣说品 (Samantabhadraparivarta)

| 维度 | 详情 |
|------|------|
| **藏文位置** | 第28品：十地品(Ch.27) 之后、十定品(Ch.29) 之前 |
| **汉文状态** | 六十华严：无 · 八十华严：无 · 四十华严：不涉及 |
| **关联汉文经典** | ⭐ **《大方广普贤所说经》**(T0847, 实叉难陀译) — **内容高度对应** |
| **别译本说明** | 实叉难陀在翻译八十华严同时另译此经为单行本（1卷），但未纳入八十华严正文。说明译者知晓此品存在但选择将其作为独立经典流通 |
| **对译策略** | 可以汉文别译本(T0847)为锚定参照，进行藏汉逐段对勘 |
| **对译优先级** | 🔴 **P0 — 最高优先**。有汉文别译可作对勘桥梁 |

## 三、B 类差异：内容实质性参差

### Ch.27 — 十地品

| 维度 | 详情 |
|------|------|
| **差异性质** | 藏文十地品可能源自更完整的梵本，结构上更接近独立流传的《十地经》(Daśabhūmika-sūtra) |
| **汉文相关文献** | 六十华严/八十华严 均含此品 |
| | 别译: 《渐备一切智德经》(T10n0285, 竺法护)、**《十住经》**(T10n0286, 鸠摩罗什)、**《佛说十地经》**(T10n0287, 尸罗达摩) |
| | 论释: 《十地经论》(T26n1522, 世亲造)、《十住毗婆沙论》(T26n1521, 龙树造) |
| **对勘策略** | 藏文本 ↔ 鸠摩罗什《十住经》 + 世亲《十地经论》注解体系 |

### Ch.40 — 离世间品

| 维度 | 详情 |
|------|------|
| **差异性质** | 藏文此品有部分独特异译段落，与汉文同名品（八十华严第38品）存在实质性内容参差 |
| **汉文相关文献** | 别译: 《度世品经》(T10n0292, 竺法护, 6卷) — 此为离世间品的早期大本别译，或与藏文版本有更多对应 |
| **对勘策略** | 三方对勘：藏文 Toh44.40 ↔ 汉文八十华严第38品 ↔ 竺法护《度世品经》 |

### Ch.33 — 寿量品

| 维度 | 详情 |
|------|------|
| **差异性质** | 藏文可能有更详尽的诸佛寿量描述 |
| **汉文相关文献** | 《显无边佛土功德经》(T10n0289, 玄奘译)、《佛说较量一切佛刹功德经》(T10n0290, 法贤译) |
| **对勘策略** | 藏文本 ↔ 玄奘别译（同为唐译，可比性强） |

## 四、C 类差异：结构/序号/开合不同

### Ch.7 — 如来名号品（序号位移）

藏文中此品位于《如来华严品》之后，品目序号从汉文的第7品变为第12品。内容基本对应但结构位置后移。

### Ch.39 — 如来出现品（版本间名称不同）

- 八十华严第37品: 《如来出现品》
- 六十华严第33品: 《宝王如来性起品》（名称不同，义理侧重各异）
- 别译: 《佛说如来兴显经》(T10n0291, 竺法护)

### Ch.41 — 入法界品（结构特殊性）

- 四十华严即此品全本（40卷，798年般若译）
- 六十华严缺此品（仅34品，420年译时梵本不全）
- 汉文有多个部分别译: 《佛说罗摩伽经》(T10n0294)、《大方广佛华严经入法界品》(T10n0295)
- 84000项目已于2021年发布此品英译(Peter Alan Roberts译)

## 六、眷属经与义理关联矩阵

以下梳理藏文独有品目和差异品目对应的汉文眷属经/别译本：

| 藏文品目 | 差异类型 | 对应汉文经典 (T编号) | 关联性质 |
|---------|---------|---------------------|---------|
| Ch.11 如来华严品 | A | T0300, T0301, T0303, T0304 | 同题材·如来不思议境界 |
| Ch.28 普贤宣说品 | A | **T0847** | ⭐ 同本别译·高度对应 |
| Ch.27 十地品 | B | T0285, **T0286**, T0287 + T1521, T1522 | 别译 + 论释 |

| Ch.33 寿量品 | B | T0289, T0290 | 同题材别译 |

> ⚠ **语境警告**: 《最胜问菩萨十住除垢断结经》(T0309) 虽以"十住"为名，法藏《华严经传记》明确判为"非十住品亦非十地品"，不可简单归入十住品别译。
