## 一、语域基准：术语古 · 句法白

| 层 | 规矩 | 回源 |
|---|---|---|
| **专名层** | 佛名／菩萨名／三昧名／世界名／法门名／供物名，一律照 `T10n0279` **繁体原字形**（如 天帝釋·世尊·獅子座·師子座取祖本用形） | M6 术语库（G6.1 逐条回源） |
| **数词层** | 藏文数值**照译祖本数词系统**：སྟོང་ཕྲག་བཅུ→十千·བྱེ་བ→俱胝/百亿（照祖本该处用形）·不用阿拉伯数字 | 同上 |
| **套语层** | རྗེས་སུ་ཡི་རང་=隨喜·བཅོམ་ལྡན་འདས=世尊·ལྷའི་དབང་པོ་བརྒྱ་བྱིན=天帝釋 等高频套语从祖本 | 同上 |
| **句法层** | 现代白话行文：句读清楚、语序顺汉语、不强仿文言虚词；允许「尔时」「佛子」等祖本套语开头 | — |
| **字形** | 新译正文**繁体字形**（与祖本并置和谐）；页面按语／疏解层简体（仓规凡例四） | 仓规 |

**反例**（M5 校订对照）：「天主帝釋遙見世尊正趨向勝殿」→ 若祖本作「天帝釋」，则「天主帝釋」属术语漂移，须改从祖本并记冲突（G6.2 单列不静默）。

## 二、偈颂处理：祖本为主 ＋ 白话为注

1. **有汉平行**（该章有 `rule=差5/差6` 配对且段级祖本对应成立——以对勘数据/勘验门禁确认）：
   - 三语卡的「汉」位呈现 **T10n0279 原句**（繁体照录，逐字回源）；
   - 模型白话译降为**按注**，前缀〔白话注·未校订〕，不冒充经文（G2.4 同源）；
2. **无汉平行**（藏独有章／祖本阙文处）：逐颂白话新译，标〔未校订〕；
3. **判定不清者**：标〔待核〕挂起，不得臆断有无平行（M0.2）。

## 三、段落结构与拼装（M4.3 合并留痕）

- 段→子单元→条目三级，每级合并/拆分**必须留痕**：`subunits`／`items`／`zh_clean.method=merged-into`（并指明 `merged_into`）／`*_compose` 记拼装规则；
- shad（།）清单条目 →「，」连接、句号收尾；句内条目 → 直接连接；en 条目空格连接；子单元间 zh 换行、en 空格；
- 拼装规则写字段（`zh_compose`），M5 校订可按字段定位重排。

## 四、信度四轴（段级 schema，随 M5 落地）

每已译段增 `confidence` 对象（缺省＝未评）：

| 轴 | 取值 | 判定者 |
|---|---|---|
| 忠实度 | `first-ok` / `tail-flaw` / `reviewed` / `unchecked` | L379 漂移复核＋M5 |
| 术语 | `consistent` / `conflict:N` / `unchecked` | 术语扫描器（机器）＋G6.2 |
| 完整度 | `complete` / `trimmed` / `subunit` / `merged` | 已有字段（机器） |
| 文体 | `raw` / `polished:L.*` | M5 校订记录 |

综合分级 ABCD ＋ `basis` 字段（无依据改译=退回 raw，G5.3 段级化）。页面公示校订覆盖率与信度分布，「可引用译文」与「模型草译」视觉分离。

## 五、双轨与存疑

- 模型译一律〔未校订〕＋引擎元信息（engine/gen_s/ts/prompt 版本）在场；
- 校订不覆盖历史：段级 `prev_attempt`、线级 `tibetan_avatamsaka_proofreading.json`（原译/校订文/依据/校订人/日期）；
- 存疑标〔待核〕·推断标〔本文判断〕·讲者之误只标不改——沿仓规铁律，不因新线降标准。
