# 藏汉华严对译规范指南

## 一、翻译原则总纲

藏文《华严经》（德格版 Toh 44）的汉译，应当遵循三条核心原则：

1. **信（Fidelity）** — 忠实于藏文底本，尤其是藏文对梵文复合词和格变化的精密还原
2. **达（Clarity）** — 以流畅的佛教汉语表达，避免清代四体合璧翻译中"机械式对译"的谬误
3. **雅（Elegance）** — 参照玄奘译经的四言文体美学，使译文具有经藏之庄严气韵

## 二、语言学要点

### 2.1 藏文语法的特殊性

藏文从7世纪起系统性仿照梵文语法创立，因而：

- **格变化丰富**：藏文用格助词（ལ་, ཀྱིས་, ནས་等）标记梵文的八格，直译为中文时易产生语序混乱
- **复合词长链**：梵文的长复合词（samāsa）在藏文中被拆解但保留逻辑关系，汉语需要补充关联词
- **定语从句后置**：藏文（如梵文）定语从句在中心词之后，汉语需要调整语序

### 2.2 避免的误区（清代四体合璧教训）

| 错误类型 | 错例（清宫译） | 正确译法 |
|---------|--------------|---------|
| 连词误译 | 将藏文选择连词 `gam` 译为"竟" | 译为"或" |
| 术语混淆 | 将 `'dogs pa`（施设/假说）译为"固执" | 译为"假名"或"施设" |
| 过度拘泥 | 将否定+可取 译为"不可取"→"不可思" | 还原"不可取" |

### 2.3 采用的翻译策略（参照玄奘译经）

**添字法**: 补充汉语语境所需虚词和关联词，使句意完整。藏文省略的代词在汉语中应补回。

```
藏文直译: "彼等一切清净，见"
玄奘体:   "彼等一切，悉皆清净，而得见已"
```

**复陈法**: 对于核心教理名相，用同义词重叠增强语势和节奏感。

```
单译: "清净"
复陈: "清净皎洁" / "清净无染"
```

**省译法**: 省略藏文中过于繁琐、不符合汉语阅读习惯的重复代词或动词。

```
藏文: "彼菩萨，彼菩萨彼处行时，彼菩萨又复..."
省译: "菩萨于彼处行时，又复..."
```

**互文法**: 调整句子语序，顺应汉语的对称美学。

```
藏文语序: "于十方一切世界，彼如来以神力，光明遍照"
互文调整: "以如来神力，光明遍照十方一切世界"
```

## 三、术语对译规范

### 3.1 通用原则

- 已有汉译华严经典中的术语，**优先沿用**《八十华严》《六十华严》既有译法
- 藏文特有品目的新术语，参考84000项目梵-藏-英术语库 → 逆向映射至汉文佛典通用译法
- 不为"创新"而自造新译名；优先选用唐代译经中已通用的译法

### 3.2 核心术语对照速查

| 梵文 | 藏文 (Wylie) | 汉文标准 | 英文参考 |
|------|-------------|---------|---------|
| dharmadhātu | chos kyi dbyings | 法界 | Dharma realm |
| tathatā | de bzhin nyid | 真如 | suchness |
| śūnyatā | stong pa nyid | 空性 | emptiness |
| tathāgatagarbha | de bzhin gshegs pa'i snying po | 如来藏 | Buddha-nature |
| bodhicitta | byang chub kyi sems | 菩提心 | mind of awakening |
| samādhi | ting nge 'dzin | 三昧 | meditative absorption |
| pratītyasamutpāda | rten cing 'brel bar 'byung ba | 缘起 | dependent origination |

完整四语术语库见 `data/translation/glossary.yaml`。

## 四、文体规范

### 4.1 经文正文

- **主体采用四言**：以四字为一顿，但不强求每一句均为四字。参照玄奘"新译"体，在语法严谨与文体优雅之间取得平衡
- **偈颂部分**：藏文偈颂通常每句9或11音节，汉译可用五言或七言。押宽韵（偶句押韵即可），不强求平仄
- **长行（散文部分）**：保持经文的庄重，但不排斥必要的白话元素。关键教理阐述处可采用"四六骈体"以增强庄重感

### 4.2 译注格式

每段翻译附三层注释：

```markdown
**译文**: 尔时，世尊入于海印三昧...

**校注**（版本对勘）: 
- 藏文此处多出"如大龙象"比喻，八十华严无此句
- 梵文残卷B: 对应 `nāga-rāja iva`（如龙王）

**义注**（义理说明）:
- "海印三昧": 佛之甚深禅定，如大海映现万象。法藏《探玄记》释...
```

### 4.3 段落编号体系

采用国际通用的 `Toh44.{chapter}.{paragraph}` 编号：

- `Toh44.11.001` = 藏文华严第11品第1段
- `Toh44.28.005` = 藏文华严第28品第5段

与汉文对应时标注 `T0279.{chapter}.{paragraph}`（八十华严）或 `T0278.{chapter}.{paragraph}`（六十华严）。

## 五、翻译工作流

```
藏文原文 (Toh 44)
    │
    ├── 1. 术语提取与对齐
    │       ├── 84000 术语库 (梵-藏-英) → 汉译方向映射
    │       └── 标注待定术语 (flag for review)
    │
    ├── 2. LLM 辅助初译
    │       ├── 提示词包含: 玄奘体规范 + 术语对照 + 上下文
    │       └── 输出: 汉英双语初稿
    │
    ├── 3. 人工审校 (核心环节)
    │       ├── 对照藏文原文逐句审核
    │       ├── 对照汉文对应品 (若有) 检查风格一致性
    │       ├── 交叉验证: 84000英译 / Dharmamitra英译
    │       └── 标注: 已审校 / 待讨论 / 存疑
    │
    └── 4. 定稿发布
            ├── 生成三语对读视图
            ├── 附科判注释
            └── 版本号标记 (便于后续修订追溯)
```

## 六、质量控制标准

| 级别 | 描述 | 标志 | 用途 |
|------|------|------|------|
| draft | LLM 初译，未经人工审校 | 🟡 | 内部参考 |
| review | 人工审校 1 轮，术语已对齐 | 🟠 | 学术交流 |
| final | 至少 2 轮审校，与汉文对应经典交叉验证 | 🟢 | 公开发布 |
| canonical | 经学术界/僧团认可 | 🔵 | 长远目标 |

## 七、翻译优先级

1. **最高优先** — 《如来华严品》(Toh44.11) 和《普贤宣说品》(Toh44.28): 汉译完全阙失
2. **高优先** — 《离世间品》(Toh44.40) 藏文异译段落
3. **中优先** — 其他品目的段落级差异
4. **低优先** — 词语级的翻译变体标注
