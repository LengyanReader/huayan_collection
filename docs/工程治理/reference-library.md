## 〇、用法约定（三步）

1. **先查本册**：需要某典籍/讲记/对读本时，先在此查路径；命中即直引，未命中再另行寻源并补登于此（原则 4「穷尽采集·分层落地」）。
2. **信度随行**：引外部库者须按分级标注——**T0 一手**（原典 CBETA/影印本）·**T1 典籍**（古注/译经）·**T2 学术/现代著作**·**T3 二手**（听录/口说/转引）。**外部库非项目权威源，引用时须回原典或影印本校字**，一时不能校者标〔外部·待核〕。
3. **不臆引·不搬运**：外部库文件（PDF/EPUB/DOCX/MP3）**不复制入库、不入 git**（大文件）；需要时就地读取、抄录所引段落并注明文件与页/时码。凡「据某书」而无实读其文者，**严禁言之**（严禁假信息）。

> **信度分级**（与 `verification-framework.md`、`CLAUDE.md` 原则 0 一致）：
> **T0** 一手原典｜**T1** 典籍（历代注疏、译经，本身即一级材料）｜**T2** 现代学术/著作｜**T3** 二手（听录、口说、笔记、转述）。
