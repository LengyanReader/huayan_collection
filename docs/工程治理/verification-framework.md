## 二、来源质量分级体系

### 2.1 三级来源可信度

| 级别 | 标识 | 定义 | 示例 |
|------|------|------|------|
| **T1 — 一级史料** | 🟢 | 可直接查阅的原始文献，有明确卷/页 | 《宋高僧传》卷五、《佛祖统纪》卷二十九、CBETA T10n0279 |
| **T2 — 二级学术** | 🟡 | 学术论文、考证著作、专题数据库 | 84000 Scholar's Room、华严专宗学院论文集 |
| **T3 — 三级记述** | 🟠 | 机构官网、百科、口述记录、网络资料 | 华严莲社官网、大华严寺法脉页面、维基百科 |
| **T0 — 待确认** | 🔴 | 尚未找到可靠来源，标记为待验证 | "网络资料""待查" |

### 2.2 标准引用格式

每条 source 字段应按以下格式书写：

```
T{1-3}|{文献名}|{卷/页}|{获取方式}
```

示例：
```
T1|《宋高僧传》卷五|CBETA T50n2061|法藏传
T2|84000 Scholar's Room|https://scholar.84000.co/...|华严部学术信息
T3|大华严寺法脉传承|https://www.huayenworld.org/dharma-lineage/|2024年访问
T0|待确认|—|需查《贤首宗付法师资记》
```

## 三、验证状态机

每个数据记录应经过以下状态流转：

```
                ┌──────────┐
                │  draft   │  初始录入，未标注来源
                └────┬─────┘
                     │ 补充 source 字段
                ┌────▼─────┐
                │ sourced  │  已标注来源
                └────┬─────┘
                     │ 人工核实来源与内容一致
                ┌────▼─────┐
                │ verified │  来源已验证，内容与出处一致
                └────┬─────┘
                     │ 至少两个独立来源确认
                ┌────▼──────┐
                │ confirmed │  多源交叉验证通过
                └────┬──────┘
                     │ 新证据出现质疑
                ┌────▼─────┐
                │ disputed │  存在争议或矛盾记载
                └──────────┘
```

对应到数据字段：
```json
{
  "id": "person_003",
  "name_zh": "法藏",
  "source": "T1|《宋高僧传》卷五|CBETA T50n2061",
  "source_alt": [
    "T1|《佛祖统纪》卷二十九|CBETA T49n2035",
    "T2|《法藏和尚传》|CBETA"
  ],
  "verification": {
    "status": "confirmed",
    "verified_by": null,
    "verified_date": null,
    "discrepancies": [],
    "notes": "生卒年《宋高僧传》作643-712，《佛祖统纪》一致"
  }
}
```

## 四、交叉验证规则

### 4.1 同一人物的多个来源（三角验证）

```
人物: 法藏 (person_003)
  ├── source: 《宋高僧传》卷五
  ├── source_alt[0]: 《佛祖统纪》卷二十九
  └── source_alt[1]: 《法藏和尚传》
  
交叉验证: 3/3 来源一致 → status: confirmed
```

### 4.2 传承边的双向验证

```
边: 杜顺 → 智俨 (MASTER_OF)
  ├── 正向: 《续高僧传》记载杜顺传智俨
  ├── 反向: 智俨传记中是否提及杜顺为师?
  └── 品目引用: 智俨著作中是否引用杜顺学说?
  
交叉验证: 至少两个方向一致 → status: confirmed
```

### 4.3 品目差异的三方确认

```
品目: Toh44.11 如来华严品
  ├── 藏文: Toh 44 目录确认有此品
  ├── 汉文: T09n0278 和 T10n0279 目录确认无此品
  └── 84000: Scholar's Room 确认此为藏文独有品目
  
交叉验证: 3/3 一致 → 差异标注可确认为 correct
```

## 五、人工验证清单

每条数据记录经人工验证时需确认以下项目：

### 人物记录
- [ ] 人名：是否与出处一致（含别名）
- [ ] 生卒年：出处是否明确记载，多个出处是否一致
- [ ] 师承关系：出处是否明确记载"某为某之师/弟子"
- [ ] 著作：出处是否列出，是否存世
- [ ] 朝代：与生卒年是否一致

### 传承边
- [ ] 关系类型 (MASTER_OF / INFLUENCED)：出处中的措辞是"师""弟子""从学"还是"影响"
- [ ] 关系存在性：双方传记中是否都确认此关系

### 品目差异
- [ ] 品名对应：藏文品名翻译是否准确
- [ ] 存在性确认：是否确实在对应版本中存在/不存在
- [ ] 内容差异：逐段对校是否发现实质性差异（而不仅仅是翻译风格差异）
