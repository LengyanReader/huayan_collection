## 一、玄记体四层法式（范本实录）

以探玄记〈夜摩宮中偈讚品〉为例：

1. **四门释题**：每品先立四门——**一释名**（题中每词训释：「天宮是處。菩薩顯人。雲集是身業自在。讚佛是語業功德。約身語處用以題名」）；**二来意**（本品何故来：「酬前……問故」）；**三宗趣**；**四释文**（「釋文中四：一集眾。二放光。三歎眾。四歎佛」）。
2. **分科树**：释文按经文自然结构立科，层层编号——「初集眾內。先此界集後十方集。前中三。初舉本位。二一一菩薩下明集來。三以正直下顯德」——**科以下有子科，子科以下有句**。
3. **随文微段引经＋训释**：以经文短语为锚（「國名堅固者」），随释其义（「表顯所依行成難壞故也」）——**「某者……故也」训释式**，一句一释。
4. **勘语随文**：疏钞自带异本勘（「然晉經亦有樂音止息，今略無者譯人之意」「梵本中上無升字下有神變」）——校勘入疏，不另立。
