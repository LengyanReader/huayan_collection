# 草稿（未定稿文档）

本目录收容**尚未定稿**的研究文档。收录判据以**文档自述为准**，不由他人代为判定：

- 文档 H1 标题或首部声明中自含「草稿 / 征求意见稿 / 未完成的调研 / 待续 / 存档」等字样者，入本目录。
- 正文顺带提及「草稿」二字（如举例、反引号引述）而 H1 无自述者，**不入**本目录。

## 定稿后的归类流程

1. **去掉文档内的草稿标记**（H1 标题的「（草稿·征求意见稿）」等，及正文相应的声明段）。
2. **移入分类目录**——按内容类型择一；**若现有分类不匹配，可新建分类目录**：

   | 目录 | 收容 |
   |------|------|
   | `工程治理/` | 架构、工作流、知识管理、技术栈、校验框架、自我进化、审计与台账 |
   | `翻译规范/` | 翻译规范、多语对读、双语标注体例 |
   | `宗派研究/` | 单一宗派的教义·法脉·学术·当代境遇通览 |
   | `祖师人物/` | 单一位祖师/人物的生平·著作·思想·影响 |
   | `经学文献/` | 经典与文献研究、文献地图、史传类研究 |
   | `跨学科对读/` | 与他领域的多语对读、比较研究 |
   | `随笔参考/` | 随笔、感悟、外部参考资料 |

3. **登记**——新建分类目录时，须同步登记于下列三处，**漏一处即静默失效**：

   - `data/evolution/evolution_config.yaml` 的 `scan.include`（否则自进化引擎漏扫）
   - `scripts/audit_style.py` 的 `RESEARCH_DOC_DIRS`（否则行文体审计漏检）
   - `scripts/verify_sources.py` 的 `RESEARCH_DOC_DIRS`（否则存疑标注覆盖率漏算）

4. **校验**——重跑 `python web/demo/scripts/build.py`，产物应仅在 `doc` 路径处变化，正文逐字节不变。

## 两点须注意

- **本目录不参与自动审计**：`evolution_config.yaml` 与两个脚本均按分类目录枚举，故草稿不会被计入「待核标注覆盖率」与行文体指标。这是**有意隔离**——未定稿文本不应拉高或拉低定稿的统计基线。
- **草稿亦可能已在前端发布**（如 `新技术与佛教`），此时移动文件须同步更新 `data/translation/topic_studies.yaml` 的 `doc` 字段（路径相对仓库根）。
