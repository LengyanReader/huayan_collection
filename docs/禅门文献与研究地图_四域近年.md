# 禅门文献与研究地图

> 面向「学界 · 佛门 · 宗门 · 教下 · 跨学科」五域的可靠文献与线索总汇，**以近年（2015–2026）研究为重心**，回连既有经典基座（1967–2004）。
> 定位：本文件是**文献地图 / 线索登记**，非定稿综述——凡一手已核者标〔确认〕，凡须回查者标〔线索〕/〔待核〕，以符〈边界自知·局限留档〉。其**分类框架与标注法即为可复用模板**，其余专题（净土·天台·唯识·华严·律…）可照此结构逐一建立自己的文献地图。
> 关联数据文件：`data/practice/chan_authentic_traces.yaml`（40 条 topic + 21 条 references + 3 组 chanref_additions）；姊妹研究：`docs/六祖南宗禅以外的禅法传统研究.md`、`docs/禅法传统_中英对读_合并.md`。
> 建立：2026-09-24 | 检索法：`WebSearch` 命中 → 逐条回溯出版社/学报/机构一手页 → 〔线索〕项留 URL 待续。

## 〇、凡例与方法（模板·可复用）

### 0.1 五域分类框架

| 域 | 界定 | 判据（何为此域之"可靠"） |
|---|---|---|
| **学界 academic** | 大学·研究所·学术出版社·同行评审期刊 | 出版社声誉 + 同行评审 + 引用可回溯 |
| **佛门 institutional** | 佛学院·宗教学院学报·佛教团体研究机构 | 机构权威 + 编辑委员会；注意弘法立场 |
| **宗门 lineage-internal** | 禅门自宗语录·灯录·清规·谱系·当代禅师著述 | 法脉亲承的一手性；须与批判史学交叉核对 |
| **教下 doctrinal-schools** | 天台/唯识/华严/三论/律等对禅的判释与交互 | 他宗立场之系统性；作为"镜子"补宗门自述之偏 |
| **跨学科 interdisciplinary** | 认知科学·神经现象学·性别研究·数字人文·批判佛教 | 方法论透明 + 一手数据可复现 |

### 0.2 可靠性分级（每条目后括注）

- **A 一手/权威**：原典校勘、权威学术出版社（Oxford/Columbia/Harvard Asia/Kuroda/BDK/法藏馆/中华书局…）、同行评审学报。
- **B 学人专著·学位论文**：单作者研究、博硕士论、学术博客（earlytibet 等）。
- **C 线索·待核**：网络百科、出版预告、检索摘要——**只作寻路，不作论断依据**。

### 0.3 年代带

- **奠基期** pre-2000（柳田、印顺、Dumoulin、McRae、Faure）——已在 yaml `references`。
- **成熟期** 2000–2014（Buswell 集成、《中国禅宗史》英译、敦煌校注推进）。
- **近年** 2015–2026——**本图重点**。

### 0.4 条目格式

`作者 ·《题名》· 出处/出版社 · 年份 ·（级别）— 一句话要旨/线索 · [可点链接]`

## 四、教下 · 他宗对禅的判释与交互（补宗门自述之偏）

> 方法：以天台/唯识/华严/三论/律诸宗之**判教与修行位次**为镜，观宗门"教外别传"之说之得失——正是本项目〈禅教融合〉《定慧等持》诸条之学理纵深。

- 华严判教之现代检讨：「華嚴判教論辨微」(airitilibrary, 2007)、「略論當代學界對華嚴判教安立空有始教與同別圓教之批評」(NTU 佛学研究藏) — 判教合理性之争，与禅之「别教一乘圆教」定位直接相关 ·（B）· [ntu PDF](https://buddhism.lib.ntu.edu.tw/FT/JA/712726.pdf)

- **禅↔华严直接接口**：「Dōgen's Treatment of Huayan Concepts of Mind-Only and One-and-All」(HAL开放取, 2021-02) — 道元(曹洞宗祖)对华严「唯心·一多」概念的接受与转化，**本项目（华严×禅）最相关之近年英文论文** ·（A）· [hal.science](https://hal.science/hal-03125135/document)

## 七、模板复用指引（供其他专题照抄结构）

1. 复制〈〇·凡例〉五域表 + 三级可靠性 + 年代带 + 条目格式四要素为骨架。
2. 每域先建**学报/工具书入口**（中/英/日/韩各一），再落**近年专著/论文**。
3. 一律"回溯一手"：条目链接指向出版社/学报/机构原页，百科·博客仅 C 级线索。
4. **缺口反哺数据文件**：以〈六〉式清单把地图照进 YAML，逐条溯源落地或标〔并存〕。
5. 每次成图：`make evolve` 记录 · 更新 `docs/next-phase-plan.md` 批次 · 相关 `references` 块同步扩录。
