# 华严经多语平行对读方案

## 一、现状分析

### 华严经现存语言版本

| 语言 | 完整度 | 载体 | 获取难度 |
|------|--------|------|---------|
| **梵文** (Sanskrit) | 残卷 | 尼泊尔写本、中亚残片 | 高 — 散落多家机构 |
| **于阗语** (Khotanese) | 残片 | 大英图书馆等 | 高 — 需专业解读 |
| **汉文** — 六十华严 | 完整 34品 | CBETA T09n0278 | 低 — 公开全文 |
| **汉文** — 八十华严 | 完整 39品 | CBETA T10n0279 | 低 — 公开全文 |
| **汉文** — 四十华严 | 完整 1品 | CBETA T10n0293 | 低 — 公开全文 |
| **藏文** (Tibetan) | 完整 45品 | BDRC/BUDA | 中 — 需申请API |
| **满文** (Manchu) | 选译 | 清代四体合璧本 | 高 |
| **英文** — Cleary | 完整 39品 | 出版物 | 中 — 需购买 |
| **英文** — Dharmamitra | 完整 39品 | 出版物 | 中 — 需购买 |
| **英文** — 84000 | 进行中 | 在线公开 | 低 — 部分已发布 |

### 已有但未覆盖华严的多语平台

| 平台 | 覆盖范围 | 华严经状态 |
|------|---------|-----------|
| BuddhaNexus (汉堡大学) | 汉-梵-巴-藏典籍 | 未覆盖华严经 |
| Open Philology (莱顿) | 汉-藏文本对齐 | 可自行构建 |
| 法鼓 DEDU 对读平台 | 唯识典籍等 | 可手动导入华严经 |
| 朱庆之教授语料库 | 法华经/维摩诘经/俱舍论 | 未覆盖华严经 |

**结论**：目前尚无华严经的完整多语平行语料库，需本项目自行构建。

## 三、实施策略

### 3.1 分品策略

不是一次性对齐全部45品，而是按优先级分批：

| 优先级 | 品目 | 语言覆盖目标 | 理由 |
|--------|------|-------------|------|
| **P0** | 第11品 如来华严品 | 藏→汉+英 | 汉文全缺，学术价值最高 |
| **P0** | 第28品 普贤宣说品 | 藏+汉(T0847)+英 | 有汉文别译可对勘 |
| **P1** | 第39品 入法界品 | 梵+藏+汉(T0279/T0293)+英(84000+Cleary) | 已有84000英译和三语术语库 |
| **P1** | 第40品 离世间品 | 藏+汉(T0279/T0292)+英 | 藏文有独特异译段落 |
| **P2** | 第26品 十地品 | 梵+藏+汉(T0279/T0286)+英 | 文献最丰富，有多部别译和论释 |
| **P3** | 其余品目 | 藏+汉+英 | 主要关注段落级差异 |

### 3.2 对读视图设计

目标呈现方式（以一行对读为例）：

### 3.3 技术实现路径

```python
# 伪代码：多语对读数据管道
class MultilingualAlignment:
    """构建一个品目的多语对读数据"""

    def build(self, chapter_id: str):
        # 1. 加载藏文原文 (Toh 44)
        tibetan = self.load_tibetan(chapter_id)

        # 2. 段落分割
        segments = self.segment_paragraphs(tibetan)

        # 3. 对每个段落，查找其他语言的对应文本
        for seg in segments:
            # 3a. 向量相似度搜索汉文对应段落
            zh_match = self.vector_search(
                seg.embedding, corpus="cbeta_huayan"
            )
            # 3b. 查找英文对应
            en_match = self.lookup_84000(seg.id) or self.lookup_cleary(seg.id)
            # 3c. 标注差异级别
            seg.diff_level = self.classify_diff(seg, zh_match)

        # 4. 生成对读视图
        return self.render_alignment(segments)
```
