# 系谱可视化研究分析 & 改进方案

> 调研日期: 2026-07-24

---

## 一、现有方案的问题

当前 D3 tree layout 的局限：

1. **单一父子假设** — D3 tree 假设每个节点只有一个父节点，无法表达海云继梦同时继承梦参(临济)和钦因(贤首)两条法脉
2. **空间割裂** — 树、地图、时间轴是三个独立视图，缺乏"这一位祖师在何时何地做什么"的一体感
3. **历史深度缺失** — 树看不出"法藏(643-712)距离宗密(780-841)有将近150年"这种时间厚度
4. **理论和修行演化不可见** — 法界观→五教十宗→禅教融合→普贤乘 这条思想发展线没有呈现

---

## 二、领域研究：系谱可视化的最佳实践

### 2.1 佛教传统：皈依境 (Refuge Tree)

藏传佛教的皈依境是最成熟的法脉可视化传统——以根本祖师为中心，向外呈**分形树状**辐射，象征"一即一切"的华严法界观。结构：

```
            ┌── 印度传承 ──┐
终极本源 ──┤              ├── 当代传承
            └── 汉地传承 ──┘
```

**启示**: 可以用放射状布局(Radial Tree / 旭日图)，以法藏为中心，向内收缩到杜顺、向外张开到当代，天然传达"法脉源流"的感觉。

### 2.2 学术方法：社会网络分析

2023年论文《Lineages as Network》(MDPI Religions) 用 SNA 方法分析《祖堂集》中的禅宗谱系，发现传统线性谱系掩盖了大量复杂的横向影响关系。网络图比树更真实。

**启示**: 不应该只画 MASTER_OF 的树，也应该展示 INFLUENCED、CONTEMPORARY 等边。这对华严宗尤其重要——澄观不是法藏直传弟子，而是"私淑"，这种关系树表达不好。

### 2.3 ChronoZoom：深度时间缩放

微软研究院的 ChronoZoom 项目提出"从宇宙大爆炸到今天的无限缩放时间轴"概念——zoom out 看千年趋势，zoom in 看个人生平。

**启示**: 时间轴不应该只是底部的窄条，而应该作为**主骨架**，人物、事件、地理都锚定在时间轴上。缩放可以切换"千年全景"和"个人传记"两个粒度。

### 2.4 Sankey/Alluvial 流图

Sankey 图天然适合表达"传承分流"——时间从左到右流动，分支的宽度代表影响力或传承人数。

**启示**: 华严四大法系(高原/云栖/雪浪/宝通)的分化是一个天然的分流场景，用流图表达非常直观。

## 三、改进方案对比

### 方案 A：时间流图 (Sankey-inspired Horizontal Flow)

```
          东晋    唐                    宋        明清       近现代      当代
          │       │                     │         │          │          │
龙树 ─────┤       │                     │         │          │          │
          │  杜顺─智俨─法藏──澄观─宗密   │         │          │          │
          │       │    │              净源──义天  │          │          │
          │       │    └──审祥(日本)    │         │          │          │
          │       │                     │  高原明昱─...──钦因─┬─海云继梦
          │       │                     │         │          │  (大华严寺)
          │       │                     │         │          │
          │       │                     │  云栖莲池─月霞─常惺─南亭─成一─贤度
          │       │                     │              (华严大学)  (华严莲社)
          │       │                     │
          │       │  李通玄(方山)       │
          └───────┴─────────────────────┴────────────────────────────
```

**优点**: 时间从左到右自然流动，历史纵深一目了然。分支汇合(海云继梦)可以表达。  
**缺点**: 竖直空间有限，36人可能挤。需要可折叠/缩放。  
**适合表达**: 历史感 ⭐⭐⭐⭐⭐、空间感 ⭐⭐、理论演化 ⭐⭐⭐

**优点**: 视觉冲击力强，佛教文化语境天然契合，"一即一切"的华严精神。  
**缺点**: 径向布局不适合标注时间；空间和理论演化难以集成。  
**适合表达**: 历史感 ⭐⭐、空间感 ⭐、理论演化 ⭐⭐、文化共鸣 ⭐⭐⭐⭐⭐

**适合表达**: 历史感 ⭐⭐⭐⭐⭐、空间感 ⭐⭐⭐、理论演化 ⭐⭐⭐⭐⭐、修行演化 ⭐⭐⭐⭐

### 方案 D：混合方案 (推荐)

**主视图** = 方案 C 分层时间轴（占顶部 60%）  
**侧视图** = 地图 + 信息面板（右侧 30%）  
**底部** = 法系筛选器

交互：
- **缩放时间轴**: zoom in → 显示人物寿命条上的传记节点；zoom out → 显示千年流派变迁
- **点击人物**: 地图飞到关联地点、信息面板展示详情、时间轴上该人物寿命条高亮脉冲
- **切换图层**: 理论演化层 / 修行谱系层 可以单独开关
- **流线**: 在时间轴上，传承关系用贝塞尔曲线连接(从上一个人的圆寂点 → 下一个人的出生点)

---

## 四、推荐：方案 D (混合方案)

### 理由

1. **历史感**: 分层时间轴是表达"一千年法脉流变"最自然的方式。寿命条让人直观感受传承的"密度"和"断层"。

2. **空间感**: 地理迁移层直接锚定在时间轴上，可以看到"华严宗的重心从长安→杭州→台北"的迁移轨迹。

3. **理论/修行演化**: 独立图层，可以清晰看到"法界观(杜顺)→五教十宗(法藏)→禅教融合(宗密)→华严大学(月霞)→普贤乘(海云继梦)"这条思想发展线。

4. **技术可行性**: 分层时间轴是 Canvas 绘制(我们已有)，加上 D3 交互层。比 ChronoZoom 的"无限缩放"简单得多，但保留了核心的"时间作主骨架"概念。

5. **渐进增强**: 先做人物传承层(核心)，再加理论层和地理层。与我们的 Loop Engineering 方法论一致。

### 不做

- **完全模仿 ChronoZoom 的无限缩放**: 实现复杂度太高，36 节点不需要
- **纯 Sankey 流图**: 人数不够多(仅36人)，流图适合数百个节点的迁移数据
- **3D 地球**: 过度设计
