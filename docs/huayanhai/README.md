## 导出方法（WizNote Web API，脚本见会话记录）

1. 登录：`POST as.wiz.cn/as/user/login` → `token` + `kbGuid` + `kbServer`
2. 目录：`GET {kbServer}/ks/category/all/{kbGuid}`（159 目录）
3. 列表：`GET {kbServer}/ks/note/list/category/{kbGuid}`（分页拉全 645 篇）
4. 下载：`GET {kbServer}/ks/note/download/{kbGuid}/{docGuid}?downloadInfo=1&downloadData=1` → 返回 `info` + `html`（正文）+ `resources`
