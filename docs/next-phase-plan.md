| 任务 | 现状 | 目标 | 来源 |

| 日本华严传承链 | 仅有审祥1人 | 审祥→良弁→实忠→等6人 | 日本佛教史/东大寺资料 |

| 越南无言通禅派 | 无 | 3-5人 | 越南佛教史 |

| 高丽华严后续 | 仅有义天1人 | 义天→教雄→…4人 | 高丽佛教史 |

### 1.2 时间轴交互增强

| 功能 | 说明 | 难度 |
|------|------|------|
| **动画播放** | 按时间推进动画(play/pause)，展示法脉演变 | 中 |
| **时间书签** | 预设视角: "华严五祖(557-841)" "高丽传入(1085)" "近现代复兴(1858-2024)" | 低 |

### 1.3 地图增强

| 功能 | 说明 |
|------|------|
| **Leaflet缓存策略** | 当前CDN直引，网络不稳定时显示"地图未加载"。增加local fallback或预检 |

## 方向二：汉藏差异深化

### 2.1 逐品内容对比 (P1)

| 品目 | 当前 | 目标 |
|------|------|------|
| Ch.11 如来华严品 | 仅标注"A类·藏文独有" | 获取藏文原文(BDRC API)→结构大纲→汉英双语初译 |
| Ch.28 普贤宣说品 | 仅标注"A类·与T0847高度对应" | 逐段对齐T0847→差异标注表(A/B/C三级) |
| Ch.27 十地品 | 标注"源自更完整梵本" | 与鸠摩罗什《十住经》+世亲《十地经论》三方对勘 |
| Ch.40 离世间品 | 标注"独特异译段落" | 与竺法护《度世品经》(T0292)对勘 |

### 2.2 对读视图

| 功能 | 说明 |
|------|------|
| **段落级对读** | 选中品目→左藏右汉逐段对比，差异处着色标注 |
| **术语高亮** | 差异品中关键术语(法界/三昧/如来)自动着色，链接到术语库 |
| **差异分级** | A级(全缺)/B级(参差)/C级(结构)/D级(微异)/E级(对应)五色标注 |

### 2.3 学界辩论追踪

| 论题 | 正方 | 反方 | 共识度 |
|------|------|------|--------|
| 藏译底本是否于阗本 | BDRC目录标注 | 部分学者认为有印度梵本中介 | 85% consensus |
| Ch.11是否独立经典后并入 | 结构分析支持 | 无直接文献证据 | disputed |
| "观世音/观自在"拼写分歧是否证明多版本 | 法藏《探玄记》记载 | 仅为音译习惯差异 | 60% consensus |

### 2.4 术语库扩充

当前25条 → 目标100+条，覆盖: 教理名相(法界/真如/缘起/空性)、修行阶位(十信/十住/十行/十回向/十地)、佛菩萨名号、世界结构(华藏世界/七处九会)

## 方向三：华严行法完备化

### 3.1 修行次第可视化

| 功能 | 说明 |
|------|------|
| **次第导航** | 五教止观五门逐层可折叠展开，每个门配图标+说明 |
| **禅法图解** | 安那般那数息观(数随止观还净)用SVG流程图展示 |
| **十信位进度指示器** | 初信→十信，每个信位配禅定/法位/检验标准卡片 |

### 3.2 音视频嵌入

| 平台 | 内容 | 嵌入方式 |
|------|------|---------|
| YouTube | 大华严寺官方频道 | iframe嵌入(需用户点击激活) |
| Bilibili | 《华严六科》42h完整版 | 外链卡片 |
| Apple Podcast | 普贤乘华严宗(20+系列) | 播客嵌入 |
| Spotify | 同上 | 嵌入式播放器 |

### 3.3 海云继梦著作体系

| 类别 | 著作 | 关键内容 |
|------|------|---------|
| 禅修入门 | 《煖身》《禅修正行》 | 安那般那数息观实操 |
| 禅法进阶 | 《禅，怎么参？》《禅观概论》 | 置心一处·参禅金三角 |

| 法脉传承 | 大华严寺官网法脉页面 | 贤首宗42世完整谱系 |

### 3.4 修行资源导航

- **禅七信息**: 大华严寺定期举办一日禅/二日禅/忍可禅七，链接到报名页面

- **线上课程**: 华严六科线上学习平台链接
