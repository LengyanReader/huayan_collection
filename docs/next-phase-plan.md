## 四、方向四：华严经版本时空演进可视化（新增）

### 4.1 概念

将华严经从印度→中亚→汉地→西藏→东亚→西方的**成书、翻译、流传过程**，以可视化方式呈现，展示「一个文本如何在千年时空跨语言跨文化传播和演变」。

### 4.2 数据基础

| 版本 | 时间 | 地点 | 语言 | 品目/卷 |
|------|------|------|------|---------|
| 龙宫原本（传说） | 约2世纪 | 印度 | 梵文 | 上中下三本·下本十万偈 |
| 支娄迦谶《兜沙经》 | 167 | 洛阳 | 汉文 | 1卷·最早华严单行经 |
| 佛驮跋陀罗《六十华严》 | 418-420 | 建康 | 汉文 | 60卷34品·七处八会 |
| 实叉难陀《八十华严》 | 695-699 | 洛阳 | 汉文 | 80卷39品·七处九会 |
| 般若《四十华严》 | 796-798 | 长安 | 汉文 | 40卷·入法界品全本 |
| 胜友/智军 藏译 | 约800-830 | 吐蕃 | 藏文 | 4册45品 |
| 尼泊尔梵文写本 | 约11-12世纪 | 加德满都 | 梵文 | 残卷 |
| 西夏文译本 | 约11-13世纪 | 西夏 | 西夏文 | 据八十华严译 |
| 回鹘文译本 | 约13-14世纪 | 高昌 | 回鹘文 | 安藏译·据汉本 |
| 满文译本 | 约18世纪 | 北京 | 满文 | 清代四体合璧 |
| Cleary英译 | 1984-1987 | 美国 | 英文 | 据八十华严 |
| Dharmamitra英译 | 2022 | 美国 | 英文 | 据八十华严·3册 |
| 84000英译 | 2021-进行中 | 国际 | 英文 | 据藏文Toh44 |

### 4.3 可视化方案

| 维度 | 方案 |
|------|------|
| **时间轴** | 横轴从2世纪到2026年，各版本按翻译/成书时间定位 |
| **空间轴** | 地图标记每个版本的翻译地点（洛阳/建康/长安/吐蕃/加德满都/美国） |
| **流派流** | 用带箭头的流线（Sankey风格）展示版本间的继承/重译/补全关系 |
| **品目变化** | 每个版本的节点大小按品目数量缩放（34→39→1→45） |
| **关联经** | 旁支经（兜沙经/十住经/度世品经等15部）以小节点连接至对应品目 |

### 4.4 技术实现

- Canvas 或 SVG 流图
- 复用现有时间轴缩放/平移逻辑
- 复用现有地图标记系统
- 新增「版本流线」图层

### 4.5 优先级

P2 — 待上述三方向稳定后再启动。属于锦上添花的可视化深化。
