## 方向一：数据深化 (P0)

### 1.1 人物补全

| 补全范围 | 数量 | 来源 |
|---------|------|------|
| 高原法系 32-36 世佚名人物 | 5人 | 《贤首宗付法师资记》 |
| 日本华严传承链（审祥→良弁→…） | 6人 | 日本佛教史 |
| 越南华严（无言通禅派） | 3人 | 学术研究 |
| 韩国华严（义天后续） | 4人 | 高丽佛教史 |
| 当代学者（魏道儒、王颂、邱高兴等） | 5人 | 学术数据库 |
| 华严莲社 4-5 世细节 | 2人 | 华严莲社资料 |
| 海外华严（美国华严莲社等） | 3人 | 网络资料 |

### 1.2 传记丰满

- 每位人物从当前 150 字扩充至 300-500 字
- 增加：具体著作年份、师承细节、历史影响评价
- 来源标注精确到卷/页码

### 1.3 地点精校

- 古代地名 → 现代坐标精校（误差 < 1km）
- 补充：日本东大寺、韩国浮石寺、越南相关道场
- 增加时间维度（人物在各地的起止年份）

## 方向二：视觉提升 (P1)

### 2.1 时间轴增强

| 功能 | 说明 |
|------|------|
| **动画播放** | 按年代自动推进时间轴，展示法脉演变（play/pause/rewind） |
| **时间书签** | 预设视角："华严五祖""高丽传入""近现代复兴" |
| **兴衰色带** | 盛唐=暖金、晚唐=暗红、宋代=淡蓝，朝代氛围感 |
| **通史事件** | 标注中国佛教史大事：玄奘译经(645)、武宗灭佛(845)、敦煌藏经洞封闭(约1000) |
| **人物照片** | 近现代人物嵌入小头像（Canvas不支持，改用HTML overlay） |

### 2.2 地图增强

| 功能 | 说明 |
|------|------|
| **时空热力图** | 按朝代显示华严道场密度变化 |
| **迁徙动画** | 点击人物→地图展示其生平迁徙轨迹（箭头+时间标注） |
| **多标记联动** | 点击人物→所有关联地点同时高亮+弹窗 |

### 2.3 整体视觉

| 改进 | 说明 |
|------|------|
| **朝代背景纹理** | 唐=敦煌纹样、宋=水墨山水、当代=简约线条 |
| **Tab过渡动画** | Tab切换有淡入淡出效果 |
| **信息面板** | 当前info-box改卡片式设计，头像占位+分栏布局 |
| **字体层级** | 标题/正文/标注 三级字体体系 |

## 方向三：交互深化 (P1)

### 3.1 法脉传承

| 功能 | 说明 |
|------|------|
| **双人对比** | 选择两人，并排显示信息+地图两地 |
| **传承链高亮** | 点击任意节点→完整师承链从初祖到当代全亮 |
| **子嗣展开** | 点击人物→右侧面板列出直传弟子+再传弟子树 |
| **导出** | 当前视图→PNG/SVG截图 |

### 3.2 汉藏差异

| 功能 | 说明 |
|------|------|
| **对读视图** | 选中品目→左藏右汉逐段对比 |
| **术语高亮** | 差异品中的关键术语自动着色链接到术语库 |
| **学界辩论** | 每条差异标注学术共识度（consensus/disputed/unknown） |

### 3.3 华严行法

| 功能 | 说明 |
|------|------|
| **次第导航** | 五教止观五门可折叠展开，完成指示器 |
| **禅法图解** | 安般守意/置心一处 用SVG图示 |
| **音视频卡片** | 嵌入播客播放器，直接可听 |
