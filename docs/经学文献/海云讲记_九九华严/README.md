## 二、体例（凡例）

### 2.1 三源互证

凡校订稿所引，逐条辨源：

- **源一 · OCR 初稿**（影像层还原）— 一切起点，标 `[OCR @ HH:MM:SS]`
- **源二 · `docs/huayanhai/` 既有讲记**（寺方 645 篇档案）— 术语与句式之参考，标 `[讲记比对 · 文件名]`
- **源三 · CBETA `T10n0279` 繁体底本** — 凡涉及经文逐字引者**必须**回源，标 `[CBETA · 卷次 · 品名]`

三源不一致时：**经文回 CBETA · 讲者口语照 OCR 原**。

### 2.2 标识符（承本仓铁律）

| 标识 | 用法 |
|---|---|
| 〔OCR 待校〕 | OCR 单源所得 · 未经二次互证 · 引用作初判可、逐字引证不可 |
| 〔待听核〕 | 疑 OCR 误识 · 无音频可校 · 存疑不改（宁缺毋造） |
| 〔本文判断〕 | 校订者依既有知识推定 · **非讲者明言** |
| 〔讲记比对〕 | 与 `docs/huayanhai/` 已有讲记同句比对所得 |
| 〔CBETA 回源〕 | 已逐字对底本 · 繁体原字形 |

### 2.3 简繁

- **经文引文**：一律 CBETA **繁体**原字形（不得以简体口语代替）
- **讲者口语**：OCR 所得**照原**（简繁混排不统一），校订者在按语中说明
- **编者按语**：一律**简体**（承《系列总纲》凡例四）
