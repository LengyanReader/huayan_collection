## 〇、凡例与方法（模板·可复用）

### 0.1 五域分类框架

| 域 | 界定 | 判据（何为此域之"可靠"） |
|---|---|---|
| **学界·英文 academic-en** | 大学出版社·同行评审期刊·英文译注 | 出版社声誉 + 同行评审 + 引用可回溯 |
| **学界·中日韩 academic-ea** | 中日韩学者专著·学报·学位论文 | 机构权威 + 编辑委员会；注意宗派立场 |
| **原典·数字化 canon-digital** | 华严经诸译·藏译·英译·电子大藏经·辞典 | 校勘/翻译主体权威；全文可点开放取 |
| **判教·行证 doctrine-practice** | 五教十宗·法界观·妄尽还源·禅教融合 | 宗义系统性；作为"镜子"补单纯书目之偏 |
| **跨学科·近年 interdisciplinary** | 哲学重构·认知·生态·艺术考古·全球佛教 | 方法论透明 + 一手数据可复现 |

### 0.2 可靠性分级（每条目后括注；对应 yaml `references` 之 `tier`）

- **A 一手/权威**：原典校勘·翻译、权威学术出版社（Oxford/Princeton/Hawai'i/Penn State/Harrassowitz/中华书局/法藏馆…）、同行评审学报、CBETA/84000/SEP。
- **B 学人专著·学位论文**：单作者研究、博硕士论、可靠书评。
- **C 线索·待核**：网络百科、检索摘要、出版预告——**只作寻路，不作论断依据**。

### 0.3 年代带

- **奠基期** pre-2000（印顺·镰田·木村·方东美·安藤·Cook·Gregory·Cleary）。
- **成熟期** 2000–2014（织田·魏道儒·王颂·Hamar 诸论·Jones·Hammerstrom）。
- **近年** 2015–2026——**本图重点**（Gimello/Girard/Hamar 新集刊·Li Kang 哲学重构·Hamar 于阗禅·Religions 系列）。

### 0.4 条目格式

`作者 ·《题名》· 出处/出版社 · 年份 ·（级别）— 一句话要旨/线索 · [可点链接](url)`
