×🗺 华严经·法脉传播路线
来源: 佛教史通行论述 + 高僧传 + 大正藏经录
🇮🇳 印度起源 (前5世纪)
菩提伽耶(佛陀成道·华严经教说处) → 中印度(马鸣·起信论) → 那烂陀寺(无著/世亲·瑜伽行派·十地经论)

🐫 西域·中亚走廊 (4-7世纪)
龟兹(鸠摩罗什·十住经) → 北天竺·罽宾(佛驮跋陀罗·般若) → 于阗(实叉难陀·藏译华严底本来源)

🇨🇳 汉地翻译·宗派建立 (4-9世纪)
长安(鸠摩罗什译场·法藏·澄观·宗密) → 洛阳(十地经论·八十华严译场) → 建康(六十华严首译) → 终南山(杜顺·华严宗创立) → 五台山(澄观·清凉国师)

📜 吐蕃分支 (9世纪)
于阗原本 → 吐蕃(胜友/智军·藏译Toh44·45品)

🌏 东亚传播 (11-13世纪)
杭州(净源·义天入宋) → 高丽开京(义天·均如) → 日本奈良(审祥·东大寺) → 京都(明惠·高山寺中兴)

🏛 近现代复兴 (17-21世纪)
杭州(续法·清代集大成) → 常熟(月霞·华严大学1914) → 台北(华严莲社1952·华严专宗学院1975) → 南投大华严寺(海云继梦·三脉汇流2008) → 苗栗(支提山动土2026)
