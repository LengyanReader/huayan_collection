> **定位**：本项目"内容 + 代码"混合仓库的**权利状态单一登记面**。凡使用/引用外部文本、图像、外链的**权利归属、许可边界、依据**都在这里显式记录，替代"隐含假设"。
> **纪律（承 [`rules.md`](rules.md) §A）**：权利状态一律**如实登记·标明依据·边界自知**。维护者声明者标"维护者声明"；独立可核证者给一手 URL；未核证者标〔待核〕，**不假称已核**。
> **不属法律意见**：本文件仅登记项目自身立场与已知事实，非对第三方权利或侵权与否的法律判定。

## 二、决策（依上述立场）

- **D1 · 不改根 LICENSE**：MIT 保留，**不引入代码/内容分离许可**——按维护者判断现况无实质侵害。
- **D2 · README 增权利披露**：在项目首页加"版权与授权披露"一节，**降低读者误解**（"公开可得" ≠ "无版权"、"MIT" ≠ "对所有第三方内容再授权"）——这是**无成本降风险**措施，即使维持 D1 也建议做。
- **D3 · 不动 1292 讲记文件**：现状保留，无授权头/去镜像等批量操作。
- **D4 · 建本 compliance.md 作单一登记面**：把立场 + 决策 + 残留风险集中可见，未来会话/权利人/合作者可一眼查阅项目自身的权利判断。
