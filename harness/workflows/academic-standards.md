# Workflow — 学术规范（Academic Standards）

> **何时用**：撰写/审校研究文档、专题、文献综述、参考文献，或做"学术化语域/体例"整理时。
> **与信息保证的分工**：`information-assurance.md` 管"**真不真**"（事实与来源），本文件管"**规不规范**"（体例、引用格式、论断强度、语域）。二者常同批进行。

## 规范来源

- 技能：`academic-research-writer`（同行评审来源 + IEEE 标准参考文献 + 来源可信度核实）、`citation-verification`（防伪造引用、常见错误）。
- 文档：`docs/reference-management.md`（文献知识库维护）、`docs/verification-framework.md`（来源分级）。
- 项目体例：`CLAUDE.md`〈编务总则 7·引用可点〉+ L.㊾ 确立的"文体凡例 + 论断分七类 + 判断与依据对照表 + GB/T 15835 数字阿拉伯化"。

## 体例清单（Checklist）

1. **引用可点**：参考文献/sources/经号给 `[text](url)`（CBETA `https://cbetaonline.dila.edu.tw/zh/T10n0279` 式、84000、NTU、出版社官网），由 `_dynMD` 渲染；无从可点者标〔无链接〕/〔待核〕。
2. **标准参考文献**：涉学术论著用 IEEE/通行格式，作者·题名·出处·年份·页/卷期齐全可回溯。
3. **论断强度校准**：区分**强因果断言**与**描述性论断**（"决定"→"直接体现/影响"、"唯一稀缺"→"真正稀缺"）；"只能"表逻辑必要性可留。每处判断**注明依据**（指回章节/文献），无据者如实标〔属推测，无文献可据〕。
4. **来源标注**：凡含数字/事实的论断须有源或回指前文；观点类分七类（推论/评估/论证/主张/预测/立场/总结）并注明凭什么。
5. **语域学术化**：口语→书面（去"把…花在…更划算"式白话），标题学术命名，散文可表格化；文言残留（此一/皆/抑或/尚有/判然）归零，但意义与来源标注一字不动。
6. **数字体例**（GB/T 15835）：年代/百分比/大数/年月日/小数阿拉伯化；**概数（数百万）、术语（十二因缘）、序数（第一章）不改**；大数用"万/亿"式。
7. **图表规范**：编号 + 名称 + 所在章 + 交叉引用 + 图表目录；中英同步；以实际渲染截图核对无重叠/溢出。
8. **中英对照**：EN 与中文同粒度同步（章数、立场、表格、图录、论断强度都要跟改）；英文块 `EN对应` 标记规范。
9. **诚实边界**：草稿标"草稿/未完成的调研·征求意见稿"；未竟之处（语种/地域/实证/案例）逐项声明；"本研究尚未完成"而非"本文尚在修订"。

## 配方

1. 加载 `academic-research-writer` / `citation-verification`；取相关记忆〈Academic Writing Evidence and Comprehensiveness Standard〉〈Academic writing style and terminology standardization〉。
2. 起草/审校 → 逐条过〈体例清单〉。
3. 机械核验（写临时 `.py`）：论断无源扫描、数字体例、文言残留、`?utm_source=`/AI 残渣、加粗密度、EN 同步。
4. `build.py` → `verify_demo.py` → 引用可点/表格/图录渲染用 headless Chrome 实测。
5. 留痕：`docs/next-phase-plan.md` + `make evolve`。

## 常见坑

- **EN 端漏同步**（改了中文没改英文块/表格/图录）——审计须显式核对英文五类：章数·立场·表格·图录·论断强度。
- **引用块内表格**被当纯文本（`common.js` `_mdFullToHTML` 早期不识别 `>` 内 `|`，L.㊾⑫ 已修，新页面若复现按同法）。
- **转换器误伤**（数字/术语批量替换）→ 用**显式映射**而非正则一刀切。
