## 维护原则

1. **忠实原文**: 引用官方表述时尽量保持原词原句，注明来源
2. **标注存疑**: 无法交叉验证的内容标注「待确认」或来源性质
3. **保留演进**: 时间线记录体系从1981至今的发展变化，不抹去历史节点
4. **定期同步**: 关注官网「最新消息」和「九九华严」讲座进展
5. **版本溯源**: 每个新增内容标注数据来源（官网页面URL或文献章节号）

## 演进轨迹关键节点

- 1981-1991: 在家讲经探索
- 1991: 梦参剃度（临济47代）
- 2008: 三脉汇流（钦因传华严衣钵 + 胜师子王菩萨传瑜伽行）
- 2011-2013: 六科/五大行法/三部曲定型
- 2023: 台北大学杰出校友
- 2024-2025: 台北大学合作·永续发展研讨会
- 2026: 九九华严五年讲座(TICC) + 支提山动土
